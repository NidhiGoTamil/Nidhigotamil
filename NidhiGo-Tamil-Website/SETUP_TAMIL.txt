GITHUB
1. Extract this entire ZIP. Do not upload the .zip itself as a GitHub project file.
2. Create a new repository (for example: NidhiGoTamil/nidhigo-tamil).
3. From the extracted project directory:
   git init
   git add .
   git commit -m "NidhiGo Tamil clean homepage and admin dashboard"
   git branch -M main
   git remote add origin https://github.com/NidhiGoTamil/nidhigo-tamil.git
   git push -u origin main

SUPABASE
1. Create/choose the Supabase project using your approved organization and plan.
2. Run supabase/migrations/001_nidhigo.sql in Supabase SQL Editor.
3. Under Authentication create an administrator user; insert their UUID in public.admin_users.
   Example SQL:
   insert into public.admin_users(user_id) values ('YOUR-ADMIN-USER-UUID');
4. Obtain project URL, publishable/anon key, service-role secret.

VERCEL
1. Import the GitHub repo into Vercel. Framework: Next.js.
2. Configure environment variables:
   NEXT_PUBLIC_SUPABASE_URL
   NEXT_PUBLIC_SUPABASE_ANON_KEY
   SUPABASE_SERVICE_ROLE_KEY (SERVER-ONLY, secret)
   NEXT_PUBLIC_SITE_URL=https://nidhigo.com
3. Deploy, test the website and admin before linking the custom domain.

LOCAL RUN
Copy .env.example to .env.local and populate credentials, then:
   npm install
   npm run build
   npm run dev
